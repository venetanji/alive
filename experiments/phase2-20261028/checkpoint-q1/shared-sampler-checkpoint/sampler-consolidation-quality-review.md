## Findings

1. **P2 — The first request timestamp and deadline start after filesystem work.** `apps/ultra/tests/check_alive_desktop.py:668` constructs `JsonLines` before `write_legacy_sample` reaches `process_publication`'s timestamp at `apps/ultra/tests/desktop_sustained.py:153`. Its constructor calls `exists()` and possibly `stat()`. If that work stalls, provenance reports a later request than the actual `process_sample()` invocation, and the five-second / remaining-wall deadline excludes that time. For example, a first call at t=10 delayed in writer initialization until t=13 records t=13, incorrectly turning a sample started at t=12 from age -2 into age +1. Capture the request monotonic time at entry to the sustained branch and pass it through to the bounded consumer; ensure initialization time counts toward the deadline. Add a deterministic test delaying writer construction and checking the original timestamp, signed age and timeout/wall behavior.

2. **P2 — Required source-equivalence test does not connect real publication to both output files across the stale wakeup.** `apps/ultra/tests/test_desktop_sustained_integration.py:41` injects a publication directly, while `apps/ultra/tests/test_desktop_sustained_integration.py:65` injects an incomplete later publication and checks only the consumer return. The actual shared-history test at `apps/ultra/tests/test_desktop_sustained_integration.py:357` checks CPU and IDs, but does not compare the written sustained and legacy group payloads. Consequently the packet does not verify the contract's end-to-end guarantee that an overdue request waits for a real later periodic write, then emits exactly one legacy row with the matching source ID, all original group fields/timestamps, and negative request age without invoking another collector. Add a controlled fake-clock/worker test that reads both actual JSONL files and compares the complete group payloads and provenance, including repeated requests and the just-over-two-second boundary. This is a missing required test, not a claim that the present mapping is wrong.
