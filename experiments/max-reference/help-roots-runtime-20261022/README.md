## Nonvisual Message Readback

Earlier Message evidence found both JS `getvalueof()` and `getattr("text")`
return null. This harness never interprets those nulls as empty text. Instead,
an original `thispatcher` attached to each expendable working root receives
`write`. The runner extracts only Message content and route/box retention facts
from the resulting private full serialization. Private full snapshots stay
outside the repository; public state contains digests and normalized content.

The first cold update must produce a nonempty serialized Message matching the
observed affix output. If that capability check fails, scoring stops and display
state stays unresolved. A successful check establishes serialized live content,
not rendered pixels, font/layout fidelity or authoring/export behavior in Ultra.
Public states retain `authored_empty` separately from `live_content.empty` and
the current parsed message. The pristine source's authored text is unchanged.

## Shared Redaction

`help_runtime.public_message(message)` accepts the named-tag receipt schema and
maps every symbol atom and nonbuiltin selector to
`symbol-sha256:<full SHA-256 of UTF-8 token>`. Numeric values and observed tags
remain unchanged. `bang`, `int`, `float`, `list`, `symbol` and `set` are explicit
protocol selector names. Native replay can call this same function after its
private transport processes the licensed source strings. `raw_selector` is
ignored. Public errors retain only a digest; the raw Max console log is private.

`public_message_state(text, authored_empty)` parses a finite simple-token
serialization profile. Quoting, separators, escapes and substitution templates
are refused rather than guessed. Source-owned string identities are evidence
of equality, not permission to reconstruct or redistribute their original text.
