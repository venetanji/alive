# Arithmetic proof notes

- Six nonnegative curves: events, root clears, event reads, parameter writes, guard comparisons, placement probes. MIDI sample-payload reads are structurally zero because final preparation rejects AUDIO tracks/buffers.
- Each used source/offset has finite and/or cyclic local profiles. Source events remain in the single original pool. A reset pulse at suffix zero includes peak held voices, complete chain roots, maximum stored source event count including the terminating/due probes, full-chain reset/restore writes, and one source boundary step. Finite profiles additionally carry clear/end pulses without synthetic note-ons. Prefix ordinary events are excluded.
- Weighted pulse envelope uses whole periods plus a residual two-pointer window; finite pulse envelope uses only the residual window. Checked additions/products and subtraction-based cyclic distances prevent wrap. At most 1026 pulses are retained; no source/song repetitions are expanded.
- Song point sets are split at B. Finite prefix and translated cyclic [B,E) envelopes are summed pointwise, bounding prefix-only, loop-only, and first-prefix-to-loop crossing windows. This deliberately overestimates possible coincident prefix/loop work, even at width one. E and subsequent points are excluded from repeated placement/grid sets; global seams are charged separately. Global nonlooping end contributes one pulse.
- Per-track placement starts/ends are deduplicated as a union. Grid and seam/end curves are added conservatively. Finite Session ends are carried by source finite profiles. Source suffix repetitions never enter placement K. K is checked nondecreasing. Every track's K[1024] is checked against six before any segment DP starts; a dense later track cannot cause earlier-track DP work.
- Each dimension's source profile maximum is spliced into at most K(w)+1 positive-length pieces, no more than seven. A transition charge is added K(w)+1 times: one for each forced boundary plus one arbitrary entry. This can duplicate a profile pulse conservatively but cannot remove a seam, clear, chase, or entry. Values are bounded before entering the existing DP so its additions cannot overflow; final transition and cross-track arithmetic is checked.
- Full-chain scheduled placement transitions reserve four steps with placements. Tracks with no placements cannot perform a placement search: Return resolves to silence; Launch reads slot/source descriptors (two steps). Repetition pulses reserve one step. Pure clock increments/comparisons are not searches. Optional 2114 and old 9252 guard ceilings are untouched.
- Pointwise per-track maxima cover either authority and any eligible source; summing tracks covers simultaneous independent phases and all authority masks. Frame/window resource checks use unchanged profile tables.
