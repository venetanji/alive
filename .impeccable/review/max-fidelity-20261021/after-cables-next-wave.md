   `docs/superpowers/specs/2026-10-22-max-cable-geometry-design.md` already covers
   authoring-only lowering, fanout independence, route hit paths, movement and

   `canvas_list_objects_test.cpp` and `canvas_list_objects.hpp` cover retained

   `check_canvas_desktop.py` cover Message cold display/prototype separation.

3. **Score int/float together.** `patch_graph.hpp`'s Int/Float switch handles
   hot/cold storage and named `send`; `canvas_numeric_ui_test.cpp` has
   `named_numeric_send` and physical-Tab dispatch seams. The retained Message
   oracle already compares typed numeric sends to two receivers. Extend the
   integration at the actual source anchors rather than adding a second store
   object or another global bus implementation.
4. **Make one explicit diagnostic disposition table.** Exact-source metadata
   policy and finite behavior results must be reviewable separately. Importer
   `complete` currently requires every diagnostic to be information-level;
   missing fonts/layout/editor policies must not disappear merely because
   executable paths pass. Keep generic import diagnostics outside the proven
