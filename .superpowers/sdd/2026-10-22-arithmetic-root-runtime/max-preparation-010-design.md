captured once per collector before any host read. Build separate fully owned
plain snapshot/shape data from those exact strings; retain no live input object

sameInputs point still checks the same current configuration, action, document

subset, whole-object-reference shortcut or omitted definition is sufficient.

boolean-versus-number identity and object-key-order independence. Failures or
exceptions flow into existing suppression/stale/first-failure behavior.

projection/helper/owner/path checks must succeed before any eligible host batch.

permission. Another request/collector cannot consume it.
