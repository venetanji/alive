## Recommended Gate

Add a distinct `controller_numeric_representation_policy`, restricted to
`root/obj-4/obj-1`, `root/obj-4/obj-24` and `root/obj-4/obj-23` under the exact
times source and four helper hashes. A private loader must verify capture002
config, seal, manifest, all sealed files and pristine source before constructing
the policy. Bind exact source-box/text and saved-rectangle hashes, the finite
capture002 evidence map, source `flonum`, controller runtime `number`, and the
measured format/getter representations. Geometry vectors and source initial
values remain private.

Keep original `maxclass`, `runtime_class` and `runtime_classes` descriptors
unchanged, including `runtime_classes == ['flonum']`. The policy is consumed
only by the controller resolver; it supplies no generic class alias and does
not use the legacy `numeric_mode_policy` key. Revisions remain explicitly
limited to the score's two pristine times revisions, with fresh live checks
for each install; capture002 itself observed revision1 only.

For the uniquely matched exact saved rectangle, admit controller `number`
only when the policy passes and fresh `getattr('format')` returns exactly a
finite scalar number 6 and fresh `getvalueof()` returns exactly one finite
numeric array element. At install, also require that value to equal the
private source UI `initial_numeric`; copy that source-bound private field into
the full-tree descriptor so both resolver passes can check it. Do not truncate
or coerce values. Missing, throwing, null, undefined, scalar-getter, nonfinite,
ambiguous-array, wrong-format, changed-geometry or changed-binding outcomes
refuse installation. A saved-class match without the explicit observed runtime
representation must not bypass a present representation policy.

Retain private request-bound controller representation observations in a
distinct ACK field, `controller_representation_observations`, deduplicated by
document/revision/anchor. Include actual format/getter outcomes and policy
identity; keep `receipt_tag_observed=false`. This records a controller binding,
not outlet typing or a validated numeric checkpoint.

## Fresh V8 Failure Diagnostics

Before strict readback class validation can fail, aggregate one private
diagnostic row for each of the same three source-bound times anchors. Bind
engine `v8`, source/helper/source-box/anchor/document/revision and readback
request/operation/step identities. Match the controller-assigned original
varname uniquely at exact saved geometry before probing. Record candidate
count, actual runtime class, geometry outcome, and read-only format/getter
outcomes using unavailable/threw/returned and typed representation distinctions.
Missing, duplicate or changed-geometry candidates produce unknown capability
outcomes while the other anchors are still observed; they never borrow another
candidate or turn unknown into zero.

Also aggregate the four exact source-root anchors' actual class/rectangle and
unique saved-name plus saved/measured-rectangle candidate bindings. Pin the
same source/helper/request/revision identities and keep all vectors private.
This is appropriate because a numeric checkpoint failure would otherwise hide
a V8 patcher representation difference until a later capture or close. Root
probes read class and geometry only; they admit no representation. Continue
the three numeric probes when a unique source-bound Basic child can be read,
even if a root class mismatch has already been recorded; otherwise retain
explicit unavailable numeric rows.

Retain the three numeric and four source-root rows in
`v8_representation_diagnostics` on the failed-readback payload. Continue to
require the original class descriptors during V8 readback
and Python checkpoint validation. An observed V8 `number` therefore still
refuses the first checkpoint even if its format/getter looks usable; the raw
failure supplies evidence for a later, separately reviewed gate. No legacy
V8 numeric alias or `jpatcher` admission is added. Existing lifecycle class
requirements remain strict. A V8 class match can proceed only through all
existing geometry, endpoint, retention and numeric getter checks.
