# Preparation008 Task Review Contract

Parent supplies a frozen task diff/map and worker report for one of the three
two-file tasks. Read those artifacts, the matching task brief, common
implementation brief and frozen design. Judge specification compliance and
code quality independently of the worker's claims. Own only the separately
named task-review report. No code/evidence writes, preparations, launches,
commits or subagents. Preserve all26private inventories and unrelated files.

Review the diff once; its context is the changed code. Read outside it only
for a concrete named interface risk, and state the risk/check in the report.
Do not rerun a suite already recorded by the worker. A focused test is allowed
only for a specific doubt the existing results do not answer. Keep source,
defaults, mode values and geometry private. Use python3 -B for imports.

Confirm every required file has its corresponding implementation/test hunk,
meaningful test-first evidence exists, synthetic negative controls reach the
claimed behavior and old behavior/tests remain. Refusal, provenance, source
set/type/shape, per-action freshness and retained histories are load-bearing
requirements. A copied factory expectation is insufficient independent proof.

For Python, emphasize historical-vs-current package independence, semantic
validation after hash rebinding, all owner rows and source-derived diagnostic
content, exact source projection/views/policy multiplicity and trusted causing
operation before record updates. For JS, emphasize closure-only authority,
mutation checks after the last getter and later retention reads, exact probe
counts, diagnostic preservation and controller coexistence. For lifecycle,
emphasize stdlib independence, owners2/3, exact close request equality, both
revisions, full Basic/root retention and history replay after digest rebinding.

Report concrete findings first with severity/file/line, then explicit spec and
quality verdicts, named focused checks and any residual unverified integration
obligation. Include a report hash when frozen. A task pass does not authorize
preparation or target launch and does not establish Max parity/qualification.
