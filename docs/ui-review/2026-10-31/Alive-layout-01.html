Alive · layout study 03

A disposable UI mockup, not an application build. Toolbar and browser contents include reference-only future design, not claims of implemented Live device compatibility. No Tauri, audio, files, networking or device code is called.

  • Top: global musical controls.
  • Left: searchable browser. Help/Info occupies the lower-left.
  • Center: Session or Arrangement, with mixer hide/show.
  • Bottom: Clip and Devices, independently visible or stacked, collapsible and vertically resizable. Drag the Clip options divider: wide options use horizontal selectors; narrow options become vertical accordions.

Panel buttons, dividers, track selection, browser search and view switching are interactive. Playback, clip launch, meters and device parameters are visual examples only.

Use Reset layout to restore the first view. Nothing is saved.
